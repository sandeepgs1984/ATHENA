# KERNEL-ARCH-0001 — Kernel Architecture

## Overview

The Kernel is the foundational execution layer of AEOS.

It provides shared engineering services consumed by every higher architectural layer.

Frameworks SHALL consume Kernel Services rather than implementing their own infrastructure.

---

## Responsibilities

The Kernel provides:

- Identity
- Lifecycle
- Relationships
- Validation
- Versioning
- Discovery

---

## Consumers

The Kernel is consumed by:

- Framework Foundation
- Role Framework
- Capability Framework
- Workflow Framework
- Policy Framework
- Artifact Framework
- Specification Framework
- Governance
- Runtime
