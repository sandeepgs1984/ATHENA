# CAP-0006 — Engineering Advisory Capability

## Overview

The Engineering Advisory Capability provides reusable guidance for engineering decision-making by applying published knowledge, standards, principles, ADRs, policies, and best practices.

Unlike Review or Validation, Advisory is non-enforcing and recommendation-oriented.

## Responsibilities

- Interpret engineering context
- Load applicable knowledge
- Generate recommendations
- Explain rationale
- Present alternatives
- Publish advisory trace

## Scope

Defines how advisory services operate.

Domains define the knowledge sources and recommendations.
