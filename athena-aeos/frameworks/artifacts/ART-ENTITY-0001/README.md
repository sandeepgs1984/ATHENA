# ART-ENTITY-0001 — Artifact Entity

## Overview

The Artifact Entity represents a persistent engineering output within AEOS.

Artifacts are immutable engineering assets that capture the results of workflows, capabilities, engineering reviews, AI agents, and documentation processes.

---

## Inheritance

The Artifact Entity extends the canonical Entity defined by MM-0001.

All common engineering properties are inherited from the Meta Model.

ART-ENTITY-0001 defines only artifact-specific characteristics.
