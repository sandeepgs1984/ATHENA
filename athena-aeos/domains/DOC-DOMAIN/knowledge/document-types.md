# Documentation Types

The Documentation Domain supports the following engineering document categories.

---

## Architecture Documentation

Describes the high-level system architecture, components, boundaries, dependencies, and design decisions.

Examples:

- High-Level Design
- Low-Level Design
- System Architecture
- Component Design

---

## API Documentation

Defines service interfaces and integration contracts.

Examples:

- REST APIs
- GraphQL APIs
- gRPC Services
- Event Contracts

---

## Design Documentation

Captures implementation approaches for engineering solutions.

Examples:

- Feature Design
- Technical Proposal
- Solution Design

---

## Operational Documentation

Documents system operation and maintenance.

Examples:

- Runbooks
- Playbooks
- Operational Guides
- Deployment Guides

---

## Development Documentation

Provides implementation guidance.

Examples:

- Coding Guidelines
- Contribution Guides
- Repository Standards
- Development Setup

---

## Governance Documentation

Documents organizational engineering policies.

Examples:

- ADRs
- Engineering Standards
- Policies
- Compliance Documents

---

## Release Documentation

Communicates software delivery information.

Examples:

- Release Notes
- Migration Guides
- Upgrade Instructions
