# Documentation Templates

This document defines the standard templates used for engineering documentation within the Documentation Domain.

---

# Architecture Document

Every architecture document SHOULD contain the following sections.

## Metadata

- Title
- Version
- Status
- Owner
- Last Updated

## Purpose

Explain why the document exists.

## Scope

Define what is included and excluded.

## System Overview

Provide a high-level description of the system.

## Architecture

Describe major components and interactions.

## Dependencies

List internal and external dependencies.

## Risks

Document known technical risks.

## Assumptions

Capture engineering assumptions.

## References

Link to related ADRs, APIs, repositories, and specifications.
