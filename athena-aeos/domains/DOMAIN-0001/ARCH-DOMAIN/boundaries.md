# Domain Boundaries

The Architecture Domain focuses on architectural engineering.

It SHALL NOT:

- Generate application code.
- Execute workflows.
- Build test suites.
- Manage repositories.
- Create deployments.

Instead, it collaborates with specialized domains through service contracts.

    ↔ Code
