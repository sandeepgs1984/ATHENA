# Code Engineering Domain (CODE-DOMAIN)

## Purpose

The Code Engineering Domain defines reusable engineering knowledge for designing, implementing, reviewing, validating, and maintaining software systems.

Unlike language-specific guidance, this domain focuses on universal engineering principles applicable across all programming languages and technology stacks.

The domain serves as the primary knowledge source for AI-assisted software engineering within AEOS.

---

# Responsibilities

The Code Domain owns:

- Engineering principles
- Coding standards
- Architectural patterns
- Design patterns
- Engineering best practices
- Code quality rules
- Code review rules
- Supported engineering artifacts

---

# Capabilities Used

The domain composes the reusable Engineering Capability Framework.

- CAP-0001 Engineering Review
- CAP-0002 Engineering Generation
- CAP-0003 Engineering Validation
- CAP-0004 Engineering Comparison
- CAP-0005 Engineering Planning
- CAP-0006 Engineering Advisory

---

# Dependencies

- EPS-0001 Engineering Package Specification
- Engineering Capability Framework

---

# Scope

This domain intentionally excludes language-specific implementation guidance.

Language-specific knowledge should be implemented as separate reusable knowledge packs.

Examples:

- Swift
- Kotlin
- Java
- C++
- Python
- JavaScript
