# Dependency Management

## Purpose

Dependency Management ensures software components collaborate predictably while remaining maintainable and testable.

---

## Principles

- Prefer explicit dependencies
- Minimize dependency count
- Depend on stable abstractions
- Avoid cyclic dependencies
- Make dependencies visible

---

## Dependency Types

- Compile-time
- Runtime
- External Service
- Infrastructure
- Configuration

---

## Best Practices

- Constructor injection
- Interface-based contracts
- Dependency inversion
- Version governance
- Replaceable implementations

---

## Anti-Patterns

- Service Locator
- Hidden globals
- Static dependency abuse
- Deep dependency chains

---

## AI Guidance

Recommend dependency reduction before introducing additional abstractions.
