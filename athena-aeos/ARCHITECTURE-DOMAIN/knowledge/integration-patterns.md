# Integration Patterns

## Purpose

Integration Patterns define how independent systems exchange information reliably and maintainably.

---

## Common Patterns

### Request–Response

Synchronous communication.

Best for immediate results.

---

### Publish–Subscribe

Event-driven communication.

Supports loose coupling.

---

### Message Queue

Reliable asynchronous processing.

Useful for background work and buffering.

---

### Event Streaming

Continuous event processing.

Suitable for analytics and real-time systems.

---

### API Gateway

Single entry point for external consumers.

---

### Backend for Frontend (BFF)

Dedicated backend optimized for a specific client.

Examples:

- Mobile
- Web
- TV
- Wearables

---

## Selection Criteria

Consider:

- Latency
- Coupling
- Throughput
- Reliability
- Consumer diversity

---

## AI Guidance

Recommend the simplest integration pattern that satisfies functional and operational requirements.
