# Security Testing

## Purpose

Security testing verifies that systems protect confidentiality, integrity and availability.

---

# Security Objectives

Validate:

- Authentication
- Authorization
- Input validation
- Session management
- Data protection
- Secure communication

---

# Verification Techniques

- Vulnerability scanning
- Penetration testing
- Dependency analysis
- Secret detection
- Static analysis
- Dynamic analysis
- Fuzz testing

---

# Common Risks

- Injection attacks
- Broken access control
- Sensitive data exposure
- Insecure configuration
- Weak authentication

---

# Security Principles

Security verification should be continuous and integrated into engineering workflows.

---

# AI Guidance

Recommend security verification for authentication, authorization, payment, administrative and externally exposed functionality.
