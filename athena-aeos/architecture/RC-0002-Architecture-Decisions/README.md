# RC-0002 — Global Architecture Decision Records

## Overview

Architecture Decision Records (ADRs) document significant repository-wide architectural decisions.

Unlike specification-level decisions, Global ADRs apply across the entire AEOS architecture.

They preserve the rationale behind important design choices and provide historical context for future evolution.

---

## Purpose

Global ADRs answer one question:

> Why was this architectural decision made?

---

## Scope

Global ADRs apply to:

- All architectural layers
- Repository governance
- Cross-layer relationships
- Architectural evolution
- Long-term design philosophy
