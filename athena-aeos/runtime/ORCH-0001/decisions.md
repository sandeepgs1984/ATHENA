# Architectural Decisions

## ADR-ORCH-0001

The Runtime Orchestrator SHALL coordinate execution without performing execution.

---

## ADR-ORCH-0002

Execution SHALL be delegated to the Execution Engine.

---

## ADR-ORCH-0003

Runtime coordination SHALL be event-driven where applicable.

---

## ADR-ORCH-0004

The Runtime Orchestrator SHALL remain independent of implementation technology.
