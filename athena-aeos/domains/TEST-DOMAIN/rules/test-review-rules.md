# Test Review Rules

## Purpose

Test reviews ensure verification assets remain effective, maintainable and aligned with engineering standards.

---

## Review Checklist

Verify:

- Requirement traceability
- Risk alignment
- Appropriate testing level
- Meaningful assertions
- Stable execution
- Test data quality
- Environment suitability
- Automation value
- Documentation completeness
- Maintainability

---

## Common Review Questions

- What risk does this test reduce?
- Is this the lowest effective verification level?
- Can this scenario be simplified?
- Is another test already covering this behavior?
- Is the verification deterministic?
- Can failures be diagnosed easily?

---

## Approval Criteria

Verification assets should not be approved unless they:

- Reduce measurable risk
- Improve engineering confidence
- Follow Verification Principles
- Comply with Test Quality Rules
