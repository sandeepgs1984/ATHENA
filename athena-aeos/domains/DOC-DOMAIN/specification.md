---

# Purpose

Provide reusable engineering knowledge for technical documentation.

---

# Scope

The domain governs:

- Documentation structure
- Documentation terminology
- Documentation quality
- Documentation templates
- Documentation metadata
- Documentation artifact definitions

---

# Out of Scope

The following are intentionally delegated to the Engineering Capability Framework:

- Review workflow
- Validation workflow
- Comparison workflow
- Planning workflow
- Advisory workflow
- Metrics
- Lifecycle
