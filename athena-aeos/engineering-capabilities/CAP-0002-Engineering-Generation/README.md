# CAP-0002 — Engineering Generation Capability

## Overview

The Engineering Generation Capability defines the standard pattern for creating engineering artifacts from structured requirements, templates, knowledge assets, and configuration.

It is reusable across all engineering domains including Architecture, Documentation, Code, API, Testing, Repository, Deployment, and Security.

---

## Responsibilities

- Accept structured inputs
- Load applicable knowledge
- Generate engineering artifacts
- Validate output completeness
- Produce generation metadata
- Publish execution trace

---

## Scope

This capability defines *how* engineering artifacts are generated.

Domain services define *what* knowledge, templates, and output formats are used.
