# Internal Developer Platform (IDP)

## Purpose

An Internal Developer Platform provides self-service engineering capabilities that accelerate software delivery while enforcing organizational standards.

---

## Core Capabilities

- Service templates
- Project bootstrapping
- Deployment automation
- Configuration management
- Secrets integration
- Monitoring integration
- Documentation
- Developer portals

---

## Platform Principles

- Self-service first
- Opinionated defaults
- Extensible workflows
- Discoverable capabilities
- Secure by default

---

## Success Metrics

- Onboarding time
- Deployment frequency
- Adoption rate
- Developer satisfaction
- Engineering productivity

---

## AI Guidance

Recommend an IDP when multiple teams repeatedly solve the same engineering problems independently.
