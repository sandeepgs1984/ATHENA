# Contributing to AEOS

Thank you for contributing to AEOS.

AEOS is developed using Architecture-First Engineering.

Every contribution follows the lifecycle below.

Idea

↓

Specification

↓

Architecture Review

↓

Approval

↓

Implementation

↓

Validation

↓

Merge

No implementation should be merged without an approved specification.

---

## Contribution Principles

- Architecture before implementation
- Keep specifications vendor-neutral
- Prefer composition over duplication
- Preserve backward compatibility
- Every change must improve engineering knowledge
