# Data Architecture

## Purpose

Data Architecture defines how information is modeled, stored, accessed and governed across systems.

---

## Principles

- Data ownership
- Consistency
- Integrity
- Availability
- Security
- Lifecycle management

---

## Architectural Considerations

- Normalization vs denormalization
- Relational vs NoSQL
- CQRS read models
- Event sourcing
- Data partitioning
- Archival strategy

---

## Governance

Establish:

- Data ownership
- Retention policies
- Backup strategy
- Recovery objectives

---

## AI Guidance

Recommend data models based on access patterns, consistency requirements and scalability objectives rather than technology preference.
