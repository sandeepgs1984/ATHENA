# API Domain Specification

| Property | Value |
|-----------|-------|
| Domain ID | API-DOMAIN |
| Name | API Engineering Domain |
| Version | 1.0.0 |
| Status | Active |
| Package Standard | EPS-0001 |

---

# Purpose

Provide reusable engineering knowledge for designing, documenting, reviewing, validating, and governing APIs.

---

# Scope

The domain governs:

- API design
- API contracts
- API documentation
- API versioning
- API security
- API performance
- API governance
- API lifecycle

---

# Out of Scope

The following concerns are delegated to technology-specific knowledge packs:

- Spring Boot implementation
- ASP.NET implementation
- Express.js implementation
- FastAPI implementation
- AWS API Gateway configuration
- Kong configuration
