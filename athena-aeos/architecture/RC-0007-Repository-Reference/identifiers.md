# Identifier Conventions

## Layer Prefixes

| Prefix | Layer |
|---------|-------|
| FD | Foundation |
| KN | Kernel |
| ENG | Engineering |
| GOV | Governance |
| META | Knowledge |
| RT | Runtime |
| APP | Applications |
| RC | Repository Consolidation |
| ADR | Architecture Decisions |

---

## Numbering Rules

- Four-digit numeric suffix.
- Sequential within a category.
- Never reuse identifiers.
- Deprecated identifiers remain reserved.

Examples:

FD-0001

RT-0007

APP-0002

ADR-0004
