# ARCH-SERV-0002 — Architecture Generator Service

## Overview

The Architecture Generator Service creates standardized architecture artifacts from engineering requirements.

The service applies AEOS engineering principles, governance rules, and reusable knowledge assets to produce consistent architecture documentation.

---

## Responsibilities

- Generate architecture specifications
- Generate repository structure
- Generate diagrams
- Generate architecture decisions
- Generate implementation roadmap

---

## Scope

This service generates architecture artifacts only.

It does not validate or review architectures.
