# Code Quality Rules

## CQ-001 Readability

Code shall be understandable without requiring external explanation.

---

## CQ-002 Complexity

Functions should remain small and focused.

Cyclomatic complexity should remain within approved engineering limits.

---

## CQ-003 Duplication

Duplicate logic should be eliminated through reusable abstractions.

---

## CQ-004 Modularity

Modules should exhibit high cohesion and low coupling.

---

## CQ-005 Testability

Business logic should be independently testable.

---

## CQ-006 Documentation

Public interfaces should be documented.

---

## CQ-007 Error Handling

Errors shall never be silently ignored.

---

## CQ-008 Performance

Avoid unnecessary allocations and expensive operations inside critical execution paths.

---

## CQ-009 Security

Code shall follow secure coding practices.

---

## CQ-010 Maintainability

Every change should improve or preserve long-term maintainability.
