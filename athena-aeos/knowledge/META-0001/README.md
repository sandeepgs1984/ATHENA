# META-0001 — Metadata Model

## Overview

The Metadata Model defines the standard descriptive information that accompanies every AEOS knowledge asset.

Metadata improves discoverability, traceability, governance, and automation without changing the meaning or implementation of the asset itself.

---

## Responsibilities

The Metadata Model is responsible for:

- Standardizing metadata
- Supporting discovery
- Supporting traceability
- Supporting governance
- Supporting validation
- Enabling automation

---

## Scope

Metadata applies to every AEOS knowledge asset, including:

- Specifications
- Frameworks
- Entities
- Policies
- Artifacts
- Governance Objects
- Knowledge Objects
