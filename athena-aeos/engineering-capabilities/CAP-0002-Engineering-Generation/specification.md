# CAP-0002

| Property | Value |
|----------|-------|
| ID | CAP-0002 |
| Name | Engineering Generation Capability |
| Version | 1.0.0 |
| Status | Active |

---

## Purpose

Provide a reusable specification for generating engineering artifacts across all AEOS domains.

---

## Responsibilities

Every Generation Capability SHALL:

- Validate generation request
- Load domain knowledge
- Apply templates and rules
- Produce engineering artifacts
- Validate completeness
- Generate execution metadata

---

## Applicable Domains

- Architecture
- Documentation
- Code
- API
- Testing
- Repository
- Planning
- Security
