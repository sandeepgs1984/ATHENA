# Cloud Architecture

## Purpose

Cloud Architecture leverages managed infrastructure and cloud-native services to improve agility, scalability and operational efficiency.

---

## Principles

- Infrastructure as Code
- Immutable infrastructure
- Elastic scaling
- Managed services
- Security by default
- Observability by design

---

## Architectural Building Blocks

- Compute
- Networking
- Storage
- Databases
- Messaging
- Identity
- Monitoring

---

## Design Considerations

- Cost optimization
- Multi-region deployment
- Disaster recovery
- Compliance
- Vendor lock-in
- Operational maturity

---

## AI Guidance

Recommend cloud-native services when they reduce operational burden without introducing unacceptable vendor dependence or architectural constraints.
