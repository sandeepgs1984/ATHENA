      Intraday operating guide

      ATHENA is advisory only. It does not place orders, does not guarantee profit, and does not remove your manual responsibility.

      1. Before market opens

      • Confirm Kite is connected and ATHENA is healthy.
      • Check the market pulse: NIFTY, BANK NIFTY, and VIX.
      • Use the guide as preparation only until live prices start.

      2. Build the work queue

      • Start with Top Current Setups, then review Trade and Watch.
      • Prefer rows marked Valid or Aging. Skip expired, stale, and no-plan rows.
      • Use Re-validate Visible when the list feels old, then respect the cooldown.

      3. Before entry

      • Open the symbol and read Advisor Status first.
      • Enter only if the live price is inside the entry zone.
      • Confirm the plan is still valid before placing any manual broker order.

      4. If price does not enter

      • Do not chase price outside the entry zone.
      • If the plan expires before entry, skip it.
      • Check again only after ATHENA re-validates the symbol.

      5. After entry

      • If price reaches the stop, the setup failed. Exit manually.
      • If price reaches the target, review profit-taking manually.
      • Do not invent new targets from the screen.

      6. End of day

      • Do not treat an intraday setup as an overnight hold.
      • Review or exit before market close unless you have a separate swing plan.
      • After market close, use ATHENA for review, not new intraday entry.
      Manual boundary: You choose the final action, position size, broker order type, and exit. ATHENA only shows the advisory setup and safety context.

      Clear all decisions & trace

      Permanently deletes every decision, its reasoning trace, your recorded responses, and realized outcomes. Does not touch portfolio positions, owner candidates, or pipeline run history. A backup of the live database is created automatically first.
