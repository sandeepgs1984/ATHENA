# WF-ENTITY-0001 — Workflow Entity

## Overview

The Workflow Entity represents a reusable engineering process within AEOS.

A workflow orchestrates Roles, Capabilities, Policies, and Artifacts to achieve a defined engineering objective.

---

## Inheritance

The Workflow Entity extends the canonical Entity defined by MM-0001.

All common engineering properties are inherited from the Meta Model.

WF-ENTITY-0001 defines only workflow-specific characteristics.
