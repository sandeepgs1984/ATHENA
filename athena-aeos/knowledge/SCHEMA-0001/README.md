# SCHEMA-0001 — Knowledge Schema

## Overview

The Knowledge Schema defines the common structure used to represent AEOS knowledge assets in a machine-readable format.

The schema provides a consistent layout for metadata, relationships, and domain-specific content while allowing each asset type to define its own business-specific fields.

---

## Responsibilities

The Knowledge Schema is responsible for:

- Standardizing knowledge structure
- Supporting validation
- Supporting serialization
- Supporting indexing
- Supporting interoperability

---

## Scope

The schema applies to all machine-readable knowledge assets within AEOS.
