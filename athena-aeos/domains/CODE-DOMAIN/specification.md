# Purpose

Provide reusable engineering knowledge for software implementation.

---

# Scope

The domain governs:

- Coding standards
- Software architecture principles
- Design patterns
- Refactoring guidance
- Code quality
- Engineering best practices

---

# Out of Scope

The following concerns are delegated to language-specific knowledge packs:

- Swift syntax
- Kotlin syntax
- Java syntax
- Python syntax
- C++ syntax
- Framework-specific implementation
