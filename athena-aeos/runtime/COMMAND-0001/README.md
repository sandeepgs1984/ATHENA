# COMMAND-0001 — Runtime Command

## Overview

A Runtime Command represents a request for work within the AEOS Runtime Layer.

Commands express intent by requesting an action from a runtime component. Unlike Runtime Events, which describe completed occurrences, Runtime Commands initiate execution.

---

## Responsibilities

The Runtime Command is responsible for:

- Requesting runtime work
- Initiating execution
- Carrying execution parameters
- Supporting automation
- Supporting orchestration

---

## Scope

Runtime Commands apply to:

- Runtime Entities
- Execution Engine
- Pipelines
- Orchestrators
- Future runtime services
