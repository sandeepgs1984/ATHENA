---

# Purpose

Provide a reusable engineering advisory capability for all AEOS domains by interpreting engineering context, published knowledge, organizational policies, standards, ADRs, and best practices.

---

# Responsibilities

Every Advisory Capability SHALL:

- Accept engineering questions
- Interpret engineering context
- Load applicable knowledge
- Evaluate available alternatives
- Generate recommendations
- Explain rationale
- Assess risks
- Generate advisory metadata

---

# Applicable Domains

- Architecture
- Documentation
- Code
- API
- Testing
- Repository
- Planning
- Security
- Observability
- Deployment
