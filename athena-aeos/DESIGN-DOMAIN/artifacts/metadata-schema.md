# Design Artifact Metadata

Required fields

| Field | Required |
|---------|----------|
| ID | Yes |
| Name | Yes |
| Owner | Yes |
| Version | Yes |
| Status | Yes |
| Review Status | Yes |
| Design Type | Yes |
| Dependencies | Optional |

Example

```yaml
metadata:
  id: DESIGN-001
  name: Authentication Module
  owner: Platform Team
  version: 1.0
  review: Approved
```
