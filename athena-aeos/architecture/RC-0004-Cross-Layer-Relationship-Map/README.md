# RC-0004 — Cross-Layer Relationship Map

## Overview

The Cross-Layer Relationship Map documents how architectural concepts relate across AEOS layers.

Unlike the Layer Dependency Matrix, which governs allowable dependencies, this document focuses on conceptual relationships and traceability.

---

## Purpose

Provide a navigable architectural map that helps contributors understand how specifications connect without violating layer boundaries.

---

## Scope

Applies to all published architectural layers and repository-wide concepts.
