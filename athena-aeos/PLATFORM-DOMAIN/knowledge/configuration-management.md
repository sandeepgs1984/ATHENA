# Configuration Management

## Purpose

Configuration Management separates deployable software from environment-specific configuration.

---

## Principles

- Externalized configuration
- Environment independence
- Versioned changes
- Auditable updates
- Secure storage

---

## Categories

- Runtime configuration
- Environment variables
- Service endpoints
- Feature configuration
- Operational tuning

---

## Anti-Patterns

Avoid:

- Hardcoded configuration
- Environment-specific builds
- Manual configuration drift
- Untracked configuration changes

---

## AI Guidance

Recommend centralized configuration management when multiple services require consistent operational settings.
