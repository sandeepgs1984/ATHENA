# KS-0006 — Discovery Service

## Overview

The Discovery Service enables locating, resolving, indexing, and navigating engineering entities across AEOS.

Discovery operates independently of storage, implementation language, and runtime.

Every engineering entity SHALL be discoverable through this service.

---

## Objectives

- Discover entities
- Resolve canonical identities
- Navigate relationships
- Support indexing
- Enable engineering search
