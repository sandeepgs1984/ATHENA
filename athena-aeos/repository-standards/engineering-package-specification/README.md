# EPS-0001 — Engineering Package Specification

## Overview

The Engineering Package Specification (EPS) defines the canonical repository structure for all reusable engineering packages within AEOS.

An Engineering Package is the smallest independently versioned, documented, and governed unit of engineering knowledge.

Examples include:

- Domains
- Services
- Capabilities
- Knowledge Packs
- Workflows
- Adapters
- Plugins
- Templates

The objective is to ensure every package has a consistent structure, lifecycle, metadata model, and governance process.
