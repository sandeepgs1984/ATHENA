# DOC-DOMAIN — Documentation Engineering Domain

## Overview

The Documentation Domain governs the creation, maintenance, validation, review, comparison, planning, and advisory functions for engineering documentation.

This domain conforms to EPS-0001 and composes the Engineering Capability Framework rather than implementing custom workflows.

## Purpose

Provide standardized engineering documentation across AEOS.

## Engineering Capabilities

- CAP-0001 Review
- CAP-0002 Generate
- CAP-0003 Validate
- CAP-0004 Compare
- CAP-0005 Plan
- CAP-0006 Advise
