# Repository Glossary

| Term | Definition |
|------|------------|
| Architecture | The structural design of AEOS. |
| Artifact | Any managed repository document or asset. |
| Capability | A reusable architectural function. |
| Command | A runtime execution request. |
| Entity | A canonical architectural object. |
| Event | A completed runtime occurrence. |
| Extension | A customization of an existing capability. |
| Framework | A collection of related architectural capabilities. |
| Knowledge | Structured architectural information. |
| Layer | A logical architectural boundary. |
| Pipeline | An ordered execution flow. |
| Plugin | A reusable runtime capability. |
| Runtime | The execution environment. |
| Session | The boundary of a runtime execution. |
| Specification | The authoritative architectural definition. |
| Workflow | A sequence of engineering activities. |
