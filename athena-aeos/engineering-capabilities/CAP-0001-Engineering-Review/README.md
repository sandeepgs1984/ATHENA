# CAP-0001 — Engineering Review Capability

## Overview

The Engineering Review Capability defines the standard pattern for performing engineering reviews across all Athena domains.

A Review evaluates an engineering artifact against defined knowledge, standards, and quality expectations to produce findings and recommendations.

This capability is reusable across Architecture, Documentation, Code, API, Testing, Repository, Security, and other domains.

---

## Responsibilities

The Review Capability is responsible for:

- Evaluating engineering artifacts
- Identifying findings
- Assessing quality
- Assigning severity
- Producing recommendations
- Generating review reports

---

## Scope

This specification defines the reusable review pattern.

Domain services provide domain-specific knowledge and rules.
