# ARCH-SERV-0006 — Architecture Governance Advisor Service

## Overview

The Architecture Governance Advisor Service provides engineering guidance based on architecture principles, governance policies, ADRs, standards, and organizational engineering practices.

Unlike validation, this service provides recommendations before engineering decisions are finalized.

---

## Responsibilities

- Interpret architecture principles
- Explain governance policies
- Recommend architectural approaches
- Identify governance risks
- Support architecture decision making

---

## Scope

The service provides advisory guidance only.

It does not approve, reject, or validate architectures.
