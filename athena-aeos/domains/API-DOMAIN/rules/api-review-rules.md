# API Review Rules

## AR-001 Business Alignment

Verify that the API supports the intended business capability.

---

## AR-002 Contract Review

Review request models, response models and schema definitions.

---

## AR-003 Naming

Review resource names, operations and field naming consistency.

---

## AR-004 Compatibility

Detect breaking changes against previously published versions.

---

## AR-005 Security

Review authentication, authorization, validation and data exposure.

---

## AR-006 Performance

Review payload size, pagination, caching and batch operations.

---

## AR-007 Documentation

Verify documentation completeness and examples.

---

## AR-008 Governance

Ensure organizational API standards are followed.

---

## AR-009 Consumer Impact

Assess migration effort and backward compatibility.

---

## AR-010 Approval

No API should be published without successful engineering review.
