# Interface Design

## Purpose

Interfaces define stable contracts between collaborating components.

---

## Design Principles

- Keep interfaces focused
- Prefer explicit behavior
- Minimize breaking changes
- Hide implementation details
- Optimize for consumers

---

## Good Interfaces

- Small
- Cohesive
- Predictable
- Versionable
- Discoverable

---

## Anti-Patterns

- Fat interfaces
- Leaky abstractions
- Boolean parameter explosion
- Ambiguous contracts

---

## AI Guidance

Recommend interfaces that express business intent rather than implementation mechanics.
