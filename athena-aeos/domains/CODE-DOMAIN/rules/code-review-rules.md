# Code Review Rules

## CR-001 Correctness

Verify the implementation satisfies the intended behavior.

---

## CR-002 Readability

Verify naming, formatting, and structure.

---

## CR-003 Architecture

Verify architectural boundaries are respected.

---

## CR-004 Reusability

Avoid duplicated implementations.

---

## CR-005 Performance

Review algorithmic complexity and resource usage.

---

## CR-006 Security

Review authentication, authorization, validation, and secret handling.

---

## CR-007 Testing

Ensure appropriate automated tests exist.

---

## CR-008 Documentation

Review API documentation and implementation comments.

---

## CR-009 Dependencies

Avoid introducing unnecessary external dependencies.

---

## CR-010 Approval

Code should not be merged until all review findings are resolved or explicitly accepted.
