# CAP-0005 — Engineering Planning Capability

## Overview

The Engineering Planning Capability defines the standard process for creating structured engineering plans, roadmaps, migration strategies, milestones, and execution sequences.

This capability is reusable across all AEOS engineering domains.

## Responsibilities

- Analyze objectives
- Identify work items
- Determine dependencies
- Create execution roadmap
- Define milestones
- Publish execution trace

## Scope

The capability defines *how* engineering planning is performed.

Individual domains define *what* is planned.
