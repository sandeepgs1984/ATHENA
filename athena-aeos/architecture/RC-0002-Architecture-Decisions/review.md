# Architecture Review

## Summary

Global ADRs establish the historical record of repository-wide architectural decisions.

They complement specification-level decisions by documenting repository-wide rationale rather than implementation details.

---

## Recommendation

Every future repository-wide architectural decision should be captured as a new ADR rather than modifying existing ADRs.

Use the status field (Proposed, Accepted, Superseded, Deprecated) to preserve decision history.
