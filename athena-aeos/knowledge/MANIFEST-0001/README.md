# MANIFEST-0001 — Repository Manifest

## Overview

The Repository Manifest provides a centralized inventory of every knowledge asset contained within AEOS.

It enables tooling and AI systems to discover repository contents without scanning every specification individually.

---

## Responsibilities

The Repository Manifest is responsible for:

- Cataloging knowledge assets
- Supporting discovery
- Supporting indexing
- Supporting dependency analysis
- Supporting validation
- Supporting automation

---

## Scope

The manifest includes all registered AEOS knowledge assets regardless of layer.
