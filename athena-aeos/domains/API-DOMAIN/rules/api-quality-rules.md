# API Quality Rules

## AQ-001 Consistency

Naming, request structure, response structure and error models shall remain consistent across all APIs.

---

## AQ-002 Contract First

Every production API shall have an approved contract before implementation.

---

## AQ-003 Documentation

Every public API shall include complete documentation and examples.

---

## AQ-004 Validation

Inputs shall be validated before processing.

---

## AQ-005 Error Handling

Errors shall follow the organization's standard error model.

---

## AQ-006 Versioning

Breaking changes require a new major version.

---

## AQ-007 Security

Protected resources shall enforce authentication and authorization.

---

## AQ-008 Performance

APIs should meet documented latency and throughput objectives.

---

## AQ-009 Observability

APIs shall expose metrics, logs and traces required for monitoring.

---

## AQ-010 Maintainability

API contracts should evolve through additive changes whenever possible.
