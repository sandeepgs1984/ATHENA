# CAP-0004

| Property | Value |
|----------|-------|
| ID | CAP-0004 |
| Name | Engineering Comparison Capability |
| Version | 1.0.0 |
| Status | Active |

## Purpose

Provide a reusable comparison specification applicable across all AEOS engineering domains.

## Responsibilities

Every Comparison Capability SHALL:

- Validate comparison request
- Load both artifacts
- Execute deterministic comparison
- Classify differences
- Assess impact
- Generate comparison metadata

## Applicable Domains

- Architecture
- Documentation
- Code
- API
- Testing
- Repository
- Security
- Deployment
