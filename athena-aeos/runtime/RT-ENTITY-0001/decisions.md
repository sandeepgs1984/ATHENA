# Architectural Decisions

## ADR-RTENTITY-0001

Every Runtime Entity SHALL execute one primary responsibility.

---

## ADR-RTENTITY-0002

Runtime Entities SHALL expose lifecycle transitions.

---

## ADR-RTENTITY-0003

Runtime Entities SHALL communicate through commands and events.

---

## ADR-RTENTITY-0004

Execution state SHALL remain local to the Runtime Entity.
