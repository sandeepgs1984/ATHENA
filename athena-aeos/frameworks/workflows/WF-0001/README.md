# WF-0001 — Workflow Framework

## Overview

The Workflow Framework defines how engineering work is orchestrated across AEOS.

It coordinates Roles, executes Capabilities in a defined sequence, applies Policies, and produces Artifacts according to Specifications.

---

## Responsibilities

The Workflow Framework is responsible for:

- Workflow orchestration
- Capability sequencing
- Role coordination
- Artifact production
- Policy enforcement
- Execution lifecycle management
