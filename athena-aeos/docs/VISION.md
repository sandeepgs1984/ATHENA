# AEOS Roadmap & Vision

## Project Vision

The project originally started as **Athena**, an AI-powered Intraday Trading Assistant.

During development, it became clear that building Athena required a reusable AI engineering foundation capable of supporting intelligent agents, engineering workflows, reusable skills and long-term extensibility.

This led to the creation of **AEOS (AI Engineering Operating System)**.

Today the relationship is defined as:

```
                 ATHENA

      Personal AI Platform
              +
   Engineering Intelligence
              +
    Intraday Trading Intelligence
              +
      Personal Knowledge Hub

                │

         Powered By

             AEOS

 AI Engineering Operating System
```

Athena is the **product**.

AEOS is the **engine**.

---

# Guiding Principle

AEOS should exist to serve Athena.

Athena should validate AEOS.

Every new capability should solve a real problem encountered while using Athena.

The roadmap therefore shifts from:

```
Build AEOS

↓

Complete Every Domain

↓

Build Athena
```

to

```
Build AEOS Core

↓

Build Athena MVP

↓

Use Athena Daily

↓

Identify Missing Capabilities

↓

Expand AEOS

↓

Improve Athena
```

This ensures development remains practical, incremental and driven by actual engineering needs.

1. AEOS Core
2. Athena MVP
3. Real-world usage

This minimizes speculative architecture and maximizes practical value.

# Development Philosophy

The project will follow these principles:

## Athena First

Athena is the product users interact with daily.

AEOS exists to power Athena.

---

## Real Usage Drives Architecture

New capabilities should originate from actual engineering challenges rather than anticipated future requirements.

---

## Build the Minimum Required Foundation

Avoid building domains that are not immediately useful.

Prefer iterative expansion.

---

## Reusable Intelligence

Every capability should be reusable across projects and domains.

---

## AI-Native Design

Every subsystem should be designed for AI consumption through:

- Knowledge
- Rules
- Prompts
- Workflows
- Contracts
- Capability descriptors

---

## Incremental Evolution

Ship working software early.

Improve continuously through feedback and daily usage.

# Success Criteria

Success is **not** measured by the number of completed domains.

Success is measured by:

- Athena becoming the primary daily engineering assistant.
- Athena solving real engineering problems.
- AEOS growing naturally through validated usage.
- Reusable engineering intelligence across domains.
- Sustainable long-term evolution.

# Final Vision

Athena is the face of the system.
