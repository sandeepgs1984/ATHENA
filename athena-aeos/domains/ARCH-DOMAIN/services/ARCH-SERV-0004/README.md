# ARCH-SERV-0004 — Architecture Comparator Service

## Overview

The Architecture Comparator Service analyzes two architecture versions and identifies structural, governance, capability, and documentation differences.

The service produces a structured comparison report to support architecture evolution, pull request reviews, migrations, and design discussions.

---

## Responsibilities

- Compare architecture specifications
- Compare repository structure
- Compare governance compliance
- Detect added, removed, and modified components
- Generate comparison reports

---

## Scope

The service compares architecture artifacts only.

It does not generate new architectures or validate compliance.
