# CAP-0003 — Engineering Validation Capability

## Overview

The Engineering Validation Capability defines the standard process for validating engineering artifacts against published rules, standards, contracts, and governance policies.

Validation is deterministic. Given identical inputs and rule sets, the outcome shall be identical.

## Responsibilities

- Validate engineering artifacts
- Execute validation rules
- Assess compliance
- Produce findings
- Generate validation reports
- Publish execution trace

## Scope

This capability defines *how* validation is performed.

Individual domains define *what* rules are evaluated.
