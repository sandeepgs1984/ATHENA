# Purpose

Define the standard engineering review model used by all review services.

---

# Capability Responsibilities

Every Review Capability SHALL:

- Evaluate an engineering artifact.
- Produce structured findings.
- Assess quality.
- Assign severity.
- Recommend improvements.
- Generate a review report.
