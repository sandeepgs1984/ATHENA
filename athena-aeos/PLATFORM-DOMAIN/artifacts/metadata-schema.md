# Platform Artifact Metadata

| Field | Required |
|--------|----------|
| ID | Yes |
| Name | Yes |
| Owner | Yes |
| Version | Yes |
| Status | Yes |
| Capability Type | Yes |
| Consumers | Optional |
| Review Status | Yes |

Example

```yaml
metadata:
  id: PLATFORM-001
  name: Configuration Service
  owner: Platform Team
  version: 1.0
  review: Approved
```
