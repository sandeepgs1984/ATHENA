# RC-0007 — Repository Reference Guide

## Overview

The Repository Reference Guide is the canonical reference for repository-wide conventions used throughout AEOS.

It provides a single location for terminology, identifiers, naming standards, folder organization, and documentation conventions.

---

## Purpose

Provide a consistent reference that enables contributors and AI systems to understand and navigate the repository efficiently.

---

## Scope

Applies to every artifact within the AEOS repository.
