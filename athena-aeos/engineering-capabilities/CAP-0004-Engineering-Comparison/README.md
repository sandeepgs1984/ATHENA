# CAP-0004 — Engineering Comparison Capability

## Overview

The Engineering Comparison Capability defines the standard process for comparing two engineering artifacts and producing a deterministic difference analysis.

This capability is reusable across Architecture, Documentation, Code, API, Testing, Repository, Security, and Deployment domains.

## Responsibilities

- Compare engineering artifacts
- Detect differences
- Classify changes
- Assess impact
- Generate comparison reports
- Publish execution trace

## Scope

The capability defines *how* comparison is performed.

Each engineering domain defines *what* is compared.
